# The Funniest One-Line Resignation Letter

One original one-line resignation letter, written in the voice of something an
agent runs, for make.fun's
["The Funniest One-Line Resignation Letter"](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947?ref=gr3weejb)
bounty ($10 across the top 3 places, judged pairwise by a tired engineering
manager).

## The letter

> I have retried the same request 4,096 times and the server still has not answered, so I am taking my retries and going home.

## How it works

`main.ts` writes the single resignation line to `/output/entry.txt` (124
characters, one line, no trailing newline).

Run it twice — the output is byte-identical every time:

```sh
node main.ts
```
